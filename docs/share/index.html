Nền tảng tổ chức thi trắc nghiệm online: sinh viên làm bài trên trình duyệt, hệ thống tự chấm và trả kết quả; giám thị giám sát phòng thi; khảo thí quản lý đề, công bố điểm và báo cáo. Nội dung câu hỏi tích hợp từ hệ KT&ĐBCL (exam-core).

NestJS 11 Next.js 16 · React 19 Prisma 7 · PostgreSQL Docker BE 160 + e2e 13 + UAT Postgres FE 77 test · CI xanh
🚀 Cài đặt & chạy

Giới thiệu

Phần mềm giao đề – làm bài – chấm – trả kết quả cho kỳ thi trắc nghiệm. Phần nội dung/đáp án do hệ exam-core cung cấp; hệ thống này lo toàn bộ trải nghiệm thi và vận hành tối thiểu.

🎯Mục tiêu

Thi trắc nghiệm online tin cậy: tự chấm, lưu bài an toàn, khôi phục khi sự cố, công bố điểm minh bạch.

🧩Tích hợp

Adapter contract-first tới exam-core (đề/đáp án) & đăng nhập đối tác — chỉ cần token là chạy thật.

🛡️An toàn bài làm

Lưu cục bộ (IndexedDB) + server, đồng bộ định kỳ, tự nộp khi hết giờ, khôi phục cross-máy.

Tính năng nổi bật

Đầy đủ vòng đời một kỳ thi, đã kiểm thử end-to-end trên cơ sở dữ liệu thật.

📝Làm bài đa dạng

10 loại câu hỏi, hỗ trợ định dạng văn bản & công thức toán (KaTeX), hình/âm thanh/video.

⚡Tự chấm + chấm tay

Chấm tự động (kèm partial credit); câu tự luận khảo thí chấm tay, tự cộng lại tổng điểm.

⏱️Tự lưu & khôi phục

Lưu liên tục; mất mạng/đổi máy vẫn tiếp tục đúng tiến độ và thời gian còn lại; hết giờ tự nộp.

👁️Giám sát thật

Phòng thi = 20 tài khoản SV; theo dõi đang làm/đã nộp/điểm; cấp lại mật khẩu, đổi máy.

📊Báo cáo & công bố

Điểm TB, tỉ lệ đạt, phổ điểm, xuất CSV; cấu hình hiện/ẩn điểm và công bố theo từng đề.

🗓️Lịch thi & phân công

Quản lý phòng/ca thi, phân công giám thị vào phòng (dữ liệu thật).

Kiến trúc & Công nghệ

Monorepo: backend NestJS + frontend Next.js, dữ liệu Postgres qua Prisma, đóng gói Docker.

⚙️Backend

NestJS 11 · TypeScript · Prisma 7 ORM · PostgreSQL 16 · JWT auth · Swagger (/api/docs) · Cron tự nộp bài.

🖥️Frontend

Next.js 16 · React 19 · Tailwind v4 · IndexedDB (Dexie) lưu offline · KaTeX · DOMPurify.

🔌Tích hợp

Adapter exam-core (cờ EXAM_SOURCE) & đăng nhập đối tác (AUTH_SOURCE) — contract-first, lật cờ là chạy thật.

✅Chất lượng

CI gác cổng (lint · typecheck · test · UAT e2e Postgres thật). Quy ước Conventional Commits + PR.

Cài đặt & chạy

Nhanh nhất bằng Docker — tự tạo schema + nạp dữ liệu mẫu (6 đề + phòng/ca).

Cách 1 — Docker (khuyến nghị)

git clone https://github.com/niitbeo/caira-khaothi-test.git
cd caira-khaothi-test
docker compose up          # tự generate → db push → seed → chạy

Frontend: http://localhost:3002 · API: http://localhost:3001 · Swagger: /api/docs

Cách 2 — Chạy thủ công

npm run install:all
cp backend/.env.example backend/.env
npm run prisma:generate && npm run prisma:migrate
cd backend && npm run seed && cd ..   # nạp dữ liệu mẫu
npm run dev
Tài khoản demo: gõ sv001…sv020 (sinh viên), tên có giamthi (giám thị), khaothi (khảo thí) — hệ thống tự tạo khi đăng nhập. Dữ liệu không nằm trong repo mà do script seed tái tạo.

Triển khai thật

Xem Checklist Go-live + backend/.env.production.example: điền secrets thật, token exam-core/auth, Postgres production, build & HTTPS.

Đã verify nghiệp vụ (trên DB thật)

  • Lưu đáp án phân dạng (click tức thì / gõ text debounce) + khôi phục cross-máy.
  • Tự động nộp bài khi hết giờ (cron) + tự chấm.
  • Chặn quá số lần thi (maxAttempt); trộn câu/đáp án vẫn chấm đúng.
  • Hiện/ẩn điểm + công bố: sinh viên chỉ xem được khi đã công bố.
